# MDDS

MDDS (Macular Disease Detection System) is an android application developed for the detection of macular diseases usng OCT images. The application uses a deep learning model to analyze an OCT image and identify the corresponding disease class. 

## Features

- Select an OCT image from the device.
- Capture an image using the camera.
- Analyze the selected image using a deep learning model.
- Display the predicted result in the android application.
- Provide a simple and easy-to-use interface.

## Technologies Used

- Kotlin
- Android studio
- TenserFlow Lite
- Git and GitHub

## Project Structure

- 'app' - Contains the main Android application code.
- 'gradle' - contains Gradle configuration files used to build the project.
- 'build.gradle.kts' - Contains project build configuration.
- 'settings.gradle.kts' - Contains project-level-settings.

## Getting Started

1. Clone the repository to your local system.
2. Open the project in Android Studio.
3. Allow Gradle to sync the Project.
4. Build and run the application on an Android device or emulater.
